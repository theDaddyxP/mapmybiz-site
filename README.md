# MapMyBiz

MapMyBiz is a simple web service that helps small businesses get listed on Google Maps quickly and easily.

### 🚀 Features
- Google Business Profile setup
- Add business location, hours, and contact info
- Upload photos and logo (Premium)
- Fast support for verification

### 💼 Pricing
- **Basic** – ₹499  
- **Premium** – ₹999 (includes logo/photo upload & optimization)
